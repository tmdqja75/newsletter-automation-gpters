3. **E-7** 청자 경어법 혼재 (해요체 ↔ 합니다체) — "~예요 / ~어요 / ~죠" 계열과 "~습니다 / ~합니다" 계열이 동일 문단 내, 심지어 연속 문장에서 교차한다. 한국어 독자는 경어법 단계 교차를 어색하게 인지한다.
   · 근거: 단락 2 — "공개 프리뷰했어요. … 주목받고 있습니다." / "깨트립니다. … 밝혔어요." — 해요체·합니다체 교차 동일 문단 내 반복.
   → 처방: 해요체로 통일. "~합니다/~습니다"를 "~해요/~어요"로 교체; 인용·공식 문체 구분이 필요한 곳만 예외 허용.

4. **C-2** 불릿 리스트 과다 — "어디에 쓸 수 있을까?" 섹션 전체가 4개 연속 불릿으로만 구성되어, 서술이 아닌 슬라이드 목록 인상을 준다. 테크 뉴스레터임에도 흐름 없이 항목 나열로 대체된 문단.

   → 처방: 2개 이하로 통합하거나, 산문 흐름 안에 녹여 서술.

5. **D-7** 패러다임 전환 공식 반복 — "속도와 성능 사이의 트레이드오프"를 깬다는 서사 구조 자체가 "X 공식 → 깨트린다 → 새 시대" 틀을 반복한다. 단락 2("이 공식을 정면으로 깨트립니다")와 마지막 문단("트레이드오프가 허물어지는 순간, 판도는 달라질 수밖에 없어요")이 동일 전환 공식의 도입·결산으로 수미쌍관 구조를 형성한다.
   · 근거: "이 공식을 정면으로 깨트립니다" (단락 2) → "트레이드오프가 허물어지는 순간" (마지막 단락) — D-7 변환 공식 2회, 글 전체의 수사 뼈대를 장악.

6. **C-4** 문단 첫 문장 요약 공식 — 각 섹션 도입 문장이 해당 섹션 전체를 한 줄로 선언하는 topic sentence 패턴이 반복된다. "속도 혁신의 주인공은 Cerebras의 웨이퍼 스케일 엔진이다", "OpenAI는 Ultrafast 모드가 특히 유용한 시나리오를 여러 개 제시했어요" 등 — 영어 five-paragraph essay 구조의 직수입.
   · 근거: 섹션 "Cerebras 웨이퍼 스케일 엔진이 핵심" 첫 문장 = 섹션 전체 요약 선언, "어디에 쓸 수 있을까?" 첫 문장 = 열거 도입 선언 — C-4 패턴 2회 이상.
